# 🕵️‍♂️ 旧事如新 - 调查员档案 (Jamais Vu)

> **极乐迪斯科风格的 TRPG 调查员档案管理系统**

这是一个专为 TRPG 跑团设计的角色卡（调查员档案）管理工具。项目采用了独特的“极乐迪斯科”（Disco Elysium）视觉美学，提供沉浸式的角色扮演体验，支持完整的角色属性、思维阁（Thought Cabinet）、物品装备等管理功能。

## ✨ 核心特性

- **🎨 极乐迪斯科美学**: 深度还原的 UI 风格与字体排版，提供极具风格化的跑团体验。
- **🧠 思维阁系统**: 独特的思维推进与内化机制，完美记录调查员的心理变化与结论推演。
- **🎒 物品与装备管理**: 方便地管理调查员的随身物品、重要线索与当前装备。
- **📱 PWA 离线支持**: 完美适配移动端（手机/平板），支持作为 PWA 独立应用安装至桌面，支持离线无缝访问。
- **🚀 现代化技术栈**: 基于 React 19 + Vite + Tailwind CSS 构建，拥有极速的响应体验。

## 🛠️ 本地运行指南

**环境要求:** Node.js (推荐 v20及以上版本)

1. 克隆项目到本地
```bash
git clone https://github.com/jeffdyuyi/jamais-vu_-----------.git
cd jamais-vu_-----------
```

2. 安装依赖
```bash
npm install
```

3. 启动本地开发服务器
```bash
npm run dev
```

## 🚀 GitHub Pages 自动化部署

本项目已经内置了 GitHub Actions 工作流。只需在 GitHub 仓库进行简单设置，即可实现自动部署。

**部署步骤:**
1. 将代码推送到 `main` 分支。
2. 进入 GitHub 仓库主页，点击 **Settings（设置）**。
3. 在左侧菜单点击 **Pages**。
4. 在 **Build and deployment** 部分，将 **Source** 更改为 **`GitHub Actions`**。
5. GitHub 会自动执行打包与部署，完成后即可通过您的 GitHub Pages 链接在线访问！
